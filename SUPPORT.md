# Support

This repository is a community-maintained boilerplate and does not include a commercial support
commitment or response-time guarantee.

- Ask setup, architecture, and usage questions in
  [GitHub Discussions](https://github.com/mzubair481/express-boilerplate/discussions).
- Report reproducible defects with the bug-report issue form.
- Propose scoped improvements with the feature-request issue form.
- Report security vulnerabilities privately according to [SECURITY.md](./SECURITY.md).

Before requesting help, use the supported Node.js and pnpm versions, search existing discussions and
issues, and run `pnpm verify`. Include relevant logs after removing credentials, tokens, cookies,
email addresses, and database connection parameters.
