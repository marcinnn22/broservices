# Security Policy

## Supported versions

Security fixes are provided for the latest major release.

| Version | Supported |
|---|---|
| 2.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, or pull request.

Use [GitHub’s private vulnerability reporting form](https://github.com/mzubair481/express-boilerplate/security/advisories/new)
and include:

- The affected endpoint, component, or configuration.
- Reproduction steps or a minimal proof of concept.
- The security impact and any known preconditions.
- A suggested mitigation, if available.

The maintainer will acknowledge a complete report as soon as practical, coordinate remediation, and
credit reporters who want public attribution. Please allow time for a fix before publishing details.

Never include real credentials, personal data, or production secrets in a report.
